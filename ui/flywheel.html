How the Flywheel Works

1
Operator Corrects
Operator flags wrong/partial fields and provides correct values during HITL review.
2
Corrections Accumulate
Each correction is stored as a (document, field, wrong value, correct value) training example.
3
DSPy Optimizes Prompt
BootstrapFewShot selects the best few-shot examples and rewrites the extraction prompt.
4
Accuracy Improves
New prompt is evaluated on held-out cases and activated if accuracy improves.
